## Instalacion

### Prerequisitos

* Nodejs 20 o 22
* Ionic v9

### Instalacion de Dependencias
```bash

   npm install 
   ionic serve
   
```

### Generar Archivos de Compilacion
se creo un archivo .yaml para ejecutar  en github actions un workflow para la generacion de archivo APK y .IPA sin firma usando cordova.
